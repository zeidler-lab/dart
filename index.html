Als App installieren

Damit die App auf dem Handy wie eine echte App startet, muss die Datei unter einer Web-Adresse liegen — z. B. auf deinem eigenen Webspace, bei Netlify Drop oder GitHub Pages.

iPhone / iPad

  1. Adresse in Safari öffnen (nicht Chrome).
  2. Teilen-Symbol antippen.
  3. „Zum Home-Bildschirm“ wählen.
  4. Name vergeben, „Hinzufügen“.

Android

  1. Adresse in Chrome öffnen.
  2. Menü (drei Punkte).
  3. „App installieren“ bzw. „Zum Startbildschirm zufügen“.

Desktop

In Chrome oder Edge erscheint rechts in der Adressleiste ein Installieren-Symbol.

Wichtig zu den Daten

Spieler und Verlauf werden auf dem Gerät gespeichert, in dem Browser, mit dem du die App geöffnet hast. Anderes Gerät heißt andere Daten. Browserdaten löschen heißt Verlauf weg.
